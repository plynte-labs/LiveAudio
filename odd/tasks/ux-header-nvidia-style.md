# UX: header, NVIDIA card, subtitle style editor

Locator: `odd/tasks/ux-header-nvidia-style.md` · Engram mirror: `odd/ux-header-nvidia-style/tasks`

## Objective
User feedback 2026-11-08 (screenshots): the header is cluttered and repeats the version; the NVIDIA home card asks to restart even after starting the service; the style tab lacks installed fonts, user-created styles in the style selector, and animation preview/timing.

## Findings (haiku map, 2026-11-08)
- Header: `.badge-header-update { display: inline-flex }` (styles.css:1650) overrides `hidden`, so the update pill always shows a static "v1.6.0". Version appears 3 times (badge, pill, About footer). "by Franguh" + (i) icon add noise.
- NVIDIA card: restart prompt gated on `nvidiaCardState === 'success' && is_running` (app.js:2775-2787); state is only reset by the card's own restart button. The live `active_backend` in ServiceStatusDto is ignored by the card. `get_gpu_backend_status` ignores `device`, while start forces ORT when device=cpu (default) — card says NVIDIA will be used but the service runs ORT. This is why the user had to pick NVIDIA options manually.
- Pin: `packaging/ct2-worker.pin.json` is a zero placeholder, so `is_published()` is false and `installed` is forced false in local builds (ct2 can never be selected; install is offered again).
- Style: font list hardcoded (subtitle-style.js:10-36), no enumeration. Saved presets live in a separate "Preset guardado" select and store tokens only (no base style). Animation select/duration only affect word-split styles (karaoke, rgb, typewriter); box enter/exit (0.4 s) and on-screen lifetime (5 s, SUB_LIFETIME_MS) are hardcoded; preview box is always `visible`, so enter/exit/lifetime never play.

## Decisions (lead defaults, 2026-11-08; user may override)
- Header: logo, name, version badge (clickable, opens About; replaces the (i) icon), status pills, language, window controls. Remove "by Franguh" from the header (credit lives in About). Update pill only when an update exists. About footer drops the duplicate version.
- NVIDIA card: driven by live state. Running on ct2_cuda -> card hidden (engine summary shows it). Installed but not active: if running -> one clear "Restart to use NVIDIA" action; if stopped -> "NVIDIA will be used on next start" (no action). Installing the runtime also sets the config so the next start uses ct2 (device cuda / asr_backend auto) — the user should not pick options by hand. Status text must honor `device`.
- Pin: set `packaging/ct2-worker.pin.json` to the real local build (sha 40eaccfb…, size 44753408, release URL) so local builds detect the installed runtime; re-pin with `build_ct2_worker.ps1 -Pin` if the exe is rebuilt.
- Style: installed fonts via DirectWrite (`windows` crate feature, no new crate) merged with the current list; user presets appear in the style selector as a "My styles" group and store their base style; animation applies to the box for every style (pop/fade/none), duration controls enter/exit, new "time on screen" control; preview gets a "Play" button that runs enter, word reveal, and exit.

## Constraints
- Strict TDD (`cargo test --workspace --locked`, `node desktop/test_frontend.js`, `node --test tests-js/*.mjs`). No commits. i18n es/en. No emojis; Lucide icons (vendored, 0.468.0). Preview must stay generated from the overlay (sync_overlay_preview_css.mjs). Font names keep clean_font validation.
